# Desktop Organizer Releases

Official releases and update repository for **Desktop Organizer**.

## 🚀 Latest Version: v2.0.1 (Experimental Update)

### What's New:
- **Two-Way Kanban & Task Sync**: Seamless drag & drop linking between task checklist items and Kanban cards with status indicators.
- **Progress & Analytics Hub**: 4 glowing KPI metric cards (Focus Time, Tasks Done, Streak, Notes) + 7-day glowing activity histogram.
- **100% Strict Workspace Isolation**: Complete isolation between multiple workspaces.
- **Zero-Delay Startup & High Performance**: Clean launch and minimal memory footprint.
